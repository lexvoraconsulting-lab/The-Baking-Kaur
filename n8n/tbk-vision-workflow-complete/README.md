## 📞 Support

### Common Issues

**Qwen GPU Down?**
- Fallback to CLIP automatically (<1s latency)
- Monitor in Datadog dashboards

**Shopify Rate Limited?**
- Expected after 20 rapid publishes
- Handled with exponential backoff
- All requests eventually process

**Database Error?**
- Connection pool retries automatically
- Check PostgreSQL service status
- Review incident runbook
