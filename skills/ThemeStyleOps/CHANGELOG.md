# Changelog — ThemeStyleOps

Every released change to this skill, newest first. Consumers pull this skill from a shared library,
so a behavioural change here reaches other repositories without them asking for it.

Versions follow `MAJOR.MINOR.PATCH`:

| S.No. | Bump | Means |
| ---: | --- | --- |
| 1 | `MAJOR` | A theme's tokens or a rule changed such that assets built before no longer match the profile |
| 2 | `MINOR` | New theme profile, new surface, or a rule relaxed; existing assets stay valid |
| 3 | `PATCH` | Wording, links, or sample assets corrected with no token or rule change |

## 2.2.0 — 2026-09-02

**MINOR** — Delivered by `LXC-AI-Skills` [`TSO`](../../Support/plans/01-skills/ThemeStyleOps/theme-style-ops-plan.md) §04 with [`DEC_20260902_B`](../../Support/decisions/DEC_20260902_B_lexvora_attribution_mark.md) (`CON005`).

- **Attribution mark** added to the `lexvora-company` profile spec (`SKILL.md` *Required output rules*): every hand-authored SVG carries a small `Lexvora (LXC)` mark in the **bottom-right corner** — `ui-monospace` `9px`, `#8a5723` at **50% glass** over a faint chip, on its own `<g class="lxc-attribution">` layer, positioned from the `viewBox`. Provenance, not decoration; sits in the outer margin only; deletable as one layer. `macos-tahoe-liquid-glass` uses the same placement with its frosted tokens.
- `references/lexvora-company.md` carries the exact markup.
- Existing usage unaffected; new SVGs must include the mark.

## 2.1.0 — 2026-09-02

**MINOR** — Delivered by `LXC-AI-Skills` [`TSO`](../../Support/plans/01-skills/ThemeStyleOps/theme-style-ops-plan.md) §03 with [`DEC_20260902_A`](../../Support/decisions/DEC_20260902_A_theme_aware_visual_generation_flow.md) (`CON004`). Part of a coordinated release with `svgImageOpsLoop` `2.1.0` and `projectops` `3.3.0`.

- **Explicit theme-resolution order** in `SKILL.md` (*Resolving the active theme*): explicit alias (this run only) → repository name contains `LXC`/`Lexvora` → `lexvora-company` → otherwise `macos-tahoe-liquid-glass` (the **new global default**). A recorded project default takes the place of the last two steps.
- **Global default changed** from `lexvora-company` to `macos-tahoe-liquid-glass`. Lexvora/LXC repositories still resolve to `lexvora-company` automatically by name; existing usage that names a theme explicitly is unaffected.
- **Stateless when called directly** — the theme is passed at runtime per call; a persisted per-repo default is `projectops`'s responsibility.
- **Paste-ready prompts** — `SKILL.md` *Paste-ready prompts* and README *Selecting a theme* now carry symmetric copy-paste lines (Lexvora ≡ Tahoe bar the theme word), both operations, a generic `<target>`, no per-surface wording. Replaces the asymmetric "Simple prompts" / "Quick Commands" blocks.

## 2.0.0 — 2026-09-01

**MAJOR BUMP** — Renamed skill `documentation-visual-theme` $\to$ **`ThemeStyleOps`** (display: *ThemeStyleOps*).
Breaking change for external consumers referencing the old skill name or path.
Expanded scope: standalone independent execution, complete design tokens engine, dual-theme generator CLI (`--theme [lexvora|tahoe|all]`),
automated SVG banner/badge pipelines, XML vector validation, and cross-platform viewer compatibility.

## 1.0.0 — 2026-09-01

First versioned release. No behavioural change — this entry records the skill's state at the point
it was given a version, per `LXC-AI-Skills` `Support/rules.md` §10 (`GC-02` / `SKL-01.20`).

The skill as it stands: two theme profiles (`lexvora-company`, `macos-tahoe-liquid-glass`) with
their alias set; the two operations (apply theme / audit theme); the shared semantic colour system;
SVG composition rules; GitHub-callout and LaTeX/MathJax presentation rules; the GitHub-rendering
constraints; the banner-and-badge system generated by `scripts/generate_theme_assets.py`; and the
rendered samples under `samples/`.

Authored history is in `LXC-AI-Skills/Support/worklog/` batches `WL-20260825-*`.
